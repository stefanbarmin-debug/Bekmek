## Контекст

- Репозиторий: https://github.com/stefanbarmin-debug/Bekmek (ветка `main`).
- В нём уже есть:
  - `.claude/skills/haiku-scout/SKILL.md`: скилл. Говорит основной модели отдавать чтение логов и поиск по файлам субагенту на Haiku, чтобы экономить лимит.

  - `PLAN.md`: этот файл.
- Claude Code сам загружает скиллы из `.claude/skills/` и агентов из `.claude/agents/`, когда репозиторий открыт как рабочая папка. Отдельно включать ничего не нужно.
- Владелец репозитория не программист и мало понимает в git. У него мало лимита, поэтому работай экономно: не перечитывай файлы повторно, не запускай лишних команд.

## Цель

Любая новая сессия Claude Code, открытая в этом репозитории, видит скилл `haiku-scout` и агента `haiku-scout` и пользуется ими без ручной настройки.

## Шаги

1. Прочитай `.claude/skills/haiku-scout/SKILL.md` и `.claude/agents/haiku-scout.md` по одному разу. Проверь:
   - frontmatter стоит в самом начале файла между строками `---` и это валидный YAML;
   - в скилле есть `name: haiku-scout` и непустой `description`;
   - в агенте есть `name: haiku-scout`, `description`, `model: haiku` и `tools`.
   Исправляй только реальные ошибки формата. Текст и логику не переписывай.
2. Создай в корне файл `CLAUDE.md` (Claude Code читает его в начале каждой сессии) с таким смыслом, коротко, по-русски:
   - чтение логов, поиск по файлам и сбор фактов из большого вывода отдавай агенту `haiku-scout`;
   - рассуждения, проектирование и правки кода делай сам;
   - отвечай пользователю по-русски и простыми словами.
   Не длиннее 10 строк.
3. Создай в корне `README.md` для владельца, по-русски, без жаргона, не длиннее 25 строк:
   - что такое haiku-scout и зачем он нужен (экономия лимита);
   - что делать: просто открывать сессию Claude Code с этим репозиторием, больше ничего;
   - как проверить, что работает: попросить «найди в репозитории все упоминания haiku» и посмотреть, что работу взял агент haiku-scout.
4. Проверь себя: вызови агента `haiku-scout` (инструмент Agent, `subagent_type: "haiku-scout"`) с задачей «перечисли файлы в .claude/ и верни их пути». Если такого типа агента в текущей сессии нет, это нормально: файлы подхватятся в следующей сессии. Просто отметь это в отчёте.
5. Закоммить изменения в `main` одним коммитом с сообщением `Add CLAUDE.md and README for haiku-scout` и запушь: `git push -u origin main`. При сетевой ошибке повтори до 4 раз с паузами 2, 4, 8, 16 секунд.
