# Экономия лимита

- Не читай файлы целиком: Grep/Glob, потом Read с offset/limit.
- Разведку (логи, поиск по репозиторию, большой вывод) отдавай субагенту `haiku-scout`.
- Не запускай Explore/general-purpose и параллельные агенты без явной просьбы.
- Для веб-поиска хватает одного инструмента; Playwright уже установлен в контейнере, браузерные MCP не нужны.
- Отвечай коротко, без пересказа сделанного и без повторного чтения только что изменённых файлов.
- Видео-скиллы (hyperframes, media-use) вызывай только если задача про видео.
